Описание:
Наш герой - это обычный парень, с обычного города N. Он работает на обычной работе и проживает обычную жизнь и, в целом, не жалуется. Но однажды — кто знает, откуда берутся подобные мысли? — его посетила идея, странная, абсурдная и даже несколько пугающая. "А что, если стать хакером?". Зачем? Почему? Разве подобные вопросы имеют значение? Возможно, это было бегство, вызов, мятеж, — быть может, даже нечто демоническое. Сказано - сделано, парень днями и ночами сидел за книгами и различными видео на всем известной площадке. Цель его была проста и дерзка: улететь в отпуск, не потратив ни копейки. Ни малейшего намёка на законность, ни малейшего страха перед последствиями. Казалось, всё его существо слилось в этой безумной идее. Прошел год, парень поднаторел и решил, что пора. Так он и оказался в аэропорту и начал думать, что же ему делать дальше...

Чтобы получить флаг необходимо любым способом записать в глобальную переменную `has_ticket` ненулевое значение.
``` C
int arrive()
{
  if ( has_ticket )
  {
    puts("Добро пожаловать на борт!");
    puts("Еще вот, вам передали: ");

    exit(0);
  }
  return puts("Простите, но у вас нет билета!\n");
}
```

Исходный код функции `print_ticket`:
``` C
unsigned __int64 print_ticket()
{
  char name[32]; // [rsp+0h] [rbp-50h] BYREF
  _BYTE ticket_id[40]; // [rsp+20h] [rbp-30h] BYREF
  unsigned __int64 canary; // [rsp+48h] [rbp-8h]

  canary = __readfsqword(0x28u);

  printf("Введите ваше ФИО: ");
  fgets(name, 32, stdin);
  printf("Очень приятно: ");
  printf(name);
  printf("Теперь введите номер посадочного талонa: ");
  gets(ticket_id);
  if ( has_ticket )
  {
    has_ticket = 1;
    puts("Возьмите ваш билет\n");
  }
  else
  {
    puts("К сожалению на ваше имя нет билета\n");
  }

  return canary - __readfsqword(0x28u);
}
```
Имеет уязвимость форматной строки и переполнения буфера.

Гипотетически имеется два вектора атаки:
1. leak canary + ROP
2. WWW

Второй вариант намного проще и быстрее, т.к. его можно полностью реализовать встроенными функциями pwntools.
