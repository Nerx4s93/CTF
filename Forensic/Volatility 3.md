### Информация о системе и ядре

| Плагин           | Описание                                                                           |
| ---------------- | ---------------------------------------------------------------------------------- |
| `windows.info`   | Общая информация о дампе: версия Windows, базовый адрес ядра, количество процессов |
| `windows.kernel` | Информация о модулях ядра и их адресах                                             |

### Процессы

| Плагин            | Описание                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------ |
| `windows.pslist`  | Список всех активных процессов (PID, имя, время запуска)                                   |
| `windows.pstree`  | Дерево процессов — показывает родитель-потомок, кто что запустил                           |
| `windows.cmdline` | Командная строка запуска для каждого процесса — раскрывает полный путь к файлу и аргументы |
| `windows.handles` | Открытые дескрипторы процесса (файлы, ключи реестра, мьютексы)                             |
| `windows.dlllist` | Загруженные DLL для каждого процесса                                                       |

### Сеть

| Плагин            | Описание                                                                   |
| ----------------- | -------------------------------------------------------------------------- |
| `windows.netscan` | Активные и недавние сетевые соединения (TCP/UDP), IP-адреса, порты, статус |
| `windows.netstat` | Похож на netscan, но только активные соединения                            |

### Файлы и образы в памяти

|Плагин|Описание|
|---|---|
|`windows.filescan`|Находит все файлы, которые есть в памяти (пути, размеры)|
|`windows.dumpfiles`|Извлекает файлы из памяти на диск для дальнейшего анализа|
|`windows.malfind`|Ищет скрытые или подозрительные участки памяти (внедрённый код, шелл-код)|

### Реестр

|Плагин|Описание|
|---|---|
|`windows.registry.hivelist`|Список загруженных кустов реестра|
|`windows.registry.printkey`|Выводит содержимое ключа реестра|
|`windows.registry.userassist`|Программы, которые пользователь запускал через GUI (из панели UserAssist)|

### Вредоносное ПО и аномалии

|Плагин|Описание|
|---|---|
|`windows.malfind`|Ищет признаки инжекта кода (подозрительные участки памяти с правами на исполнение)|
|`windows.modscan`|Сканирует модули ядра, ищет скрытые драйверы|
|`windows.driverscan`|Находит драйверы в памяти, включая скрытые|
|`windows.ssdt`|Таблица системных сервисов — может показать хуки (перехваты)|

### Пользователи и безопасность

|Плагин|Описание|
|---|---|
|`windows.privileges`|Привилегии, назначенные процессам|
|`windows.sessions`|Пользовательские сессии (кто залогинен)|
|`windows.hashdump`|Извлекает хэши паролей из памяти (требует прав)|
