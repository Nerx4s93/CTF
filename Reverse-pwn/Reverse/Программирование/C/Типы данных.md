- char
- unsigned char
- signed char

- short
	Псевдонимы: short int, signed short и signed short int.
- unsigned short
	Псевдоним: unsigned short int.

- int
	Псевдонимы: signed int и signed
- unsigned int
	Псевдоним: unsigned

- long
	4 байта (32 бита) или 8 байт (64 бита).
    На 64-разрядном Windows long занимает 4 байта, а на 64-разрядных Linux/MacOS - 8 байт.
    Псевдонимы long int, signed long int и signed long.
- unsigned long
    Имеет псевдоним unsigned long int.
    
- long long.
	8 байт (64 бита).
    Имеет псевдонимы long long int, signed long long int и signed long long.
- unsigned long long
    Имеет псевдоним unsigned long long int.
    
- float
	Диапазон: +/- 3.4E-38 до 3.4E+38.
	Занимает 4 байта (32 бита)
- double
	Диапазон: +/- 1.7E-308 до 1.7E+308.
	Занимает 8 байт (64 бита)
- long double.
	Диапазон: +/- 3.4E-4932 до 1.1E+4932
	Занимает 10 байт (80 бит). На некоторых системах может занимать 96 и 128 бит.
    
- void: тип без значения
