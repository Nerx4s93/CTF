Описание:
В этой лабораторной работе содержится уязвимость обхода пути при отображении изображений товаров.
Чтобы решить лабораторную работу, получите содержимое файла /etc/passwd.


GET запрос на /image?filename=name позволяет прочитать любой файл на диске.

Необходимо прочитать `/etc/passwd`, для этого надо сделать запрос на `GET /image?filename=../../../etc/passwd`:
