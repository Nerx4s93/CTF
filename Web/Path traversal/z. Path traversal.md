Эти уязвимости позволяют злоумышленнику читать произвольные файлы на сервере, на котором запущено приложение.

Это может включать:
- Код и данные приложения.
- Учётные данные для серверных систем.
- Конфиденциальные файлы операционной системы.

В некоторых случаях злоумышленник может получить возможность записывать данные в произвольные файлы на сервере, что позволяет ему изменять данные или поведение приложения и в конечном итоге получить полный контроль над сервером.
