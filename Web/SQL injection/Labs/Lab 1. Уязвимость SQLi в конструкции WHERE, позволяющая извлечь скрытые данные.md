Описание:
```
Данная лабораторная работа начального уровня содержит уязвимость к SQL-инъекции в фильтре категорий товаров, где приложение выполняет запрос вида:

SELECT * FROM products WHERE category = 'Gifts' AND released = 1

Для прохождения задания необходимо осуществить SQL-инъекцию с целью отображения скрытых или невыпущенных товаров.
```

Сайт фильтрует товары в GET запросе:
![](../../../z.%20Images/{FB7A911F-7F6F-44F4-A7E7-ABFE0149839E}.png)
Необходимо сформировать такой payload, чтобы было видно все категории.

Для этого в исходном запросе (`SELECT * FROM products WHERE category = 'Gifts' AND released = 1`) необходимо закрыть кавычку после Gifts и вставить выражение `OR 1=1`, что означает, что подходит каждый элемент в таблице.

Payload:`Gifts' OR 1=1--`
