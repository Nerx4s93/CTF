Описание:
Эта лабораторная работа содержит уязвимость SQL-инъекции. Приложение использует cookie отслеживания для аналитики и выполняет SQL-запрос, содержащий значение отправленного cookie. Результаты SQL-запроса не возвращаются.
База данных содержит отдельную таблицу с именем users со столбцами username и password. Чтобы решить лабораторную работу, найдите способ раскрыть пароль пользователя administrator, а затем войдите в его аккаунт.
