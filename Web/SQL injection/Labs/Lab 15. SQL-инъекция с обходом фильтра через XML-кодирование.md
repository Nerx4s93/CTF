Описание:
Эта лабораторная работа содержит уязвимость SQL-инъекции в функции проверки наличия товара. Результаты запроса возвращаются в ответе приложения.
База данных содержит таблицу users, которая содержит имена пользователей и пароли зарегистрированных пользователей. Чтобы решить лабораторию, выполните атаку SQL-инъекции для извлечения учётных данных пользователя admin, затем войдите в его аккаунт.
