Описание:
Эта лабораторная работа содержит уязвимость SQL-инъекции в фильтре категорий товаров. Результаты запроса возвращаются в ответе приложения, поэтому вы можете использовать атаку типа UNION для извлечения данных из других таблиц.
База данных содержит другую таблицу с именем users со столбцами username и password.
Чтобы решить лабораторную работу, выполните SQL-инъекцию типа UNION, которая извлекает все имена пользователей и пароли, и используйте эту информацию, чтобы войти в систему как пользователь administrator.
