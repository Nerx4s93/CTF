Описание:
Эта лабораторная работа содержит уязвимость SQL-инъекции в фильтре категорий товаров. Результаты запроса возвращаются в ответе приложения.
Приложение имеет функцию входа в систему, и база данных содержит таблицу, в которой хранятся имена пользователей и пароли. Нужно определить имя этой таблицы и столбцы, которые она содержит, а затем извлечь содержимое таблицы, чтобы получить имя пользователя и пароль всех пользователей.
Чтобы решить лабораторную работу, войдите в систему как пользователь administrator.

Запрос содержит два столбца:

Payload:
`' UNION SELECT table_name,NULL FROM information_schema.tables--`
