Описание:
```
Эта лабораторная работа содержит уязвимость слепой SQL-инъекции. Приложение использует отслеживающий cookie-файл для аналитики и выполняет SQL-запрос, содержащий значение отправленного cookie.

Результаты SQL-запроса не возвращаются, и сообщения об ошибках не отображаются. Но приложение включает сообщение "Welcome back" (С возвращением) на странице, если запрос возвращает какие-либо строки.

База данных содержит другую таблицу с именем users со столбцами username и password.

Чтобы решить лабораторную работу, войдите в систему как пользователь administrator.
```
