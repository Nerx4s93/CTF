\Если приложение перехватывает ошибки базы данных при выполнении SQL-запроса и корректно их обрабатывает, в ответе приложения не будет никакой разницы.

В такой ситуации часто можно проэксплуатировать уязвимость слепой SQL-инъекции, вызывая временные задержки в зависимости от того, истинно или ложно внедрённое условие. Поскольку SQL-запросы обычно обрабатываются приложением синхронно, задержка выполнения SQL-запроса также задерживает HTTP-ответ.

Техники вызова временной задержки зависят от используемой базы данных.

Пример для Microsoft SQL Server:
```
'; IF (1=2) WAITFOR DELAY '0:0:10'--
'; IF (1=1) WAITFOR DELAY '0:0:10'--
```
Первый из этих вводов не вызывает задержку, потому что условие 1=2 ложно.
Второй ввод вызывает задержку в 10 секунд, потому что условие 1=1 истинно.

Используя эту технику, можно извлекать данные, проверяя по одному символу за раз:
```
'; IF (SELECT COUNT(Username) FROM Users WHERE Username = 'Administrator' AND SUBSTRING(Password, 1, 1) > 'm') = 1 WAITFOR DELAY '0:0:{delay}'--
```
