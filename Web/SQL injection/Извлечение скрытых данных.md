Например, приложение для покупок, которое отображает товары в различных категориях. При клике по категории «Подарки», браузер запрашивает следующий URL-адрес:
`https://insecure-website.com/products?category=Gifts`
Это заставляет приложение отправить SQL-запрос в базу данных для извлечения информации о соответствующих товарах:
`SELECT * FROM products WHERE category = 'Gifts' AND released = 1`

Этот SQL-запрос просит базу данных вернуть:
- все данные (`*`)
- из таблицы `products`
- где категория (`category`) — `Gifts`
- и флаг выпуска (`released`) равен `1`.
`released = 1` используется, чтобы скрыть товары, которые еще не были выпущены в продажу. Для невыпущенных товаров значение `released` равно `0`.

Приложение не реализует никаких мер защиты от SQL-инъекций. Это означает, что злоумышленник может, к примеру, провести следующую атаку:
`https://insecure-website.com/products?category=Gifts'--`
Это приводит к следующему SQL-запросу:
`SELECT * FROM products WHERE category = 'Gifts'--' AND released = 1`

Можно использовать похожую атаку, чтобы заставить приложение отобразить все товары в любой категории:
`https://insecure-website.com/products?category=Gifts'+OR+1=1--`
Это приводит к следующему SQL-запросу:
`SELECT * FROM products WHERE category = 'Gifts' OR 1=1--' AND released = 1`
