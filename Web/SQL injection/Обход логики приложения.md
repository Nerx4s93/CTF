Например, приложение, которое позволяет пользователям входить в систему с помощью имени пользователя и пароля. Если пользователь вводит имя `wiener` и пароль `bluecheese`, приложение проверяет эти учетные данные, выполняя следующий SQL-запрос:
`SELECT * FROM users WHERE username = 'wiener' AND password = 'bluecheese'`
Если запрос возвращает данные пользователя, вход в систему считается успешным. В противном случае попытка входа отклоняется.

Злоумышленник может войти в систему под видом любого пользователя, даже не зная его пароля с помощью последовательности символов комментария SQL `--`, чтобы удалить проверку пароля из оператора `WHERE` в запросе. Например, отправка имени пользователя `administrator'--` и пустого пароля приведет к следующему запросу:
`SELECT * FROM users WHERE username = 'administrator'--' AND password = ''`
Этот запрос возвращает данные пользователя с именем `administrator` и успешно авторизует атакующего под этой учетной записью.
