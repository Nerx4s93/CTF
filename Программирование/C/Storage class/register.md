Является рекомендацией для компилятора поместить переменную не в оперативную память, а в регистр процессора. Доступ к регистрам значительно быстрее, чем к памяти, поэтому это может оптимизировать производительность
В современных компиляторах почти не используется, так как они самостоятельно выполняют оптимизацию.

Пример применения:
``` C
void fastLoop() {
    register int i; // Просьба к компилятору использовать регистр для i
    for (i = 0; i < 1000000; i++) {
        // ... какая-то быстрая операция
    }
}
```

Характеристики:
- Область видимости: Локальная.
- Жизненный цикл: Локальный.
- К `register`-переменной нельзя применить оператор взятия адреса `&`, так как у нее нет адреса в памяти.
- Компилятор может проигнорировать это указание, если нет свободных регистров или если тип данных не подходит для хранения в регистре.
