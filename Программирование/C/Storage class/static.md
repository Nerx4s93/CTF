Имеет два основных применения в зависимости от контекста: для локальных переменных и для глобальных переменных/функций.

### Локальные static-переменные
Когда применяется к локальной переменной, он изменяет ее жизненный цикл, сохраняя ее значение между вызовами функции. 
Характеристики:
- Область видимости: Локальная, как у `auto` переменных.
- Жизненный цикл: Существует в течение всего времени выполнения программы, а не только внутри функции.
- Начальное значение: Инициализируется только один раз при первом вызове функции. Если не инициализирована явно, получает значение 0.
``` C
#include <stdio.h>
 
void counter() {
    static int count = 0; // Инициализируется только один раз
    count++;
    printf("Count: %d\n", count);
}
 
int main() {
    counter(); // Count: 1
    counter(); // Count: 2
    counter(); // Count: 3
    return 0;
}
```

### Глобальные переменные и функции со static
Когда применяется к глобальной переменной или функции, он ограничивает их область видимости текущим файлом. К такой переменной или функции нельзя будет обратиться из другого файла с помощью `extern`. 
Характеристики:
- Область видимости: действие переменной/функции ограничено файлом, в котором они объявлены.
- Жизненный цикл: переменная/функция существует в течение всего времени выполнения программы.

Пример, пусть у нас есть файл **file1.c**:
``` C
// Файл file1.c
static int secret = 42; // Доступна только в file1.c
 
static void secretFunction() { // Доступна только в file1.c
    // ...
}
```

Полезно для сокрытия деталей реализации модуля.
